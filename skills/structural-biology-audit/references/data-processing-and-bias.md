# 处理流程与偏倚：按声明审计

按实际处理流程追问证据来源；论文中的流程图、代表性 2D class 或最终 map 不能单独复现颗粒筛选和分类。缺少粒子栈、半图或关键参数时，明确限定结论强度。

## 粒子选择与分类

- 根据结论需要索取处理流程、各轮颗粒数量与筛选记录、2D/3D classes、类别占比、分类参数、mask 和所用重构；若不同构象或组成来自同一实验，核对它们之间的关系。**本审计建议：**这些信息用于判断粒子筛选和分类是否支撑具体结构解释。社区报告建议强烈鼓励归档粒子栈，并指出相关数据和元数据有助于复核及重处理；它没有把上述每项都定为单篇论文的统一交付清单。([kleywegt2024] DOI [10.1107/S2052252524001246](https://doi.org/10.1107/S2052252524001246)，§2.1 Recommendations 7–8、§3.3.6)
- 分类输出取决于使用的统计模型和输入的类别数。RELION 的理论模型把 K 作为已知参数，并由用户设定要同时精修的模型数；论文也说明该优化是局部的，结果会依赖起始模型。**本审计判断：**只有当生物学结论依赖某个离散类别时，才按疑点和可用数据考察合理替代 K、初始化或粒子子集下结果是否稳定，并寻找独立实验或清楚的局部密度支持；这不是论文规定的普遍重跑要求。([relion2012] DOI [10.1016/j.jsb.2012.09.006](https://doi.org/10.1016/j.jsb.2012.09.006)，§2.1、§5 Conclusions)
- 若声称“某结构特征只存在于某一类”，检查该类的粒子数、局部密度和类选择是否与该特征的发现相互独立。若结论只在事后挑出的少数粒子或一个对合理处理变化不稳定的类别中出现，应降低结论强度。**这属于本审计的证据判断，不是 RELION 论文给出的统一阈值或强制测试。**([relion2012] DOI [10.1016/j.jsb.2012.09.006](https://doi.org/10.1016/j.jsb.2012.09.006)，§2.1、§5 Conclusions)

## 参考模型、预测先验与对称性

- 记录起始 map/model 的来源、低通滤波分辨率、参考生成方法、对称性、mask、重构及精修软件和关键参数。RELION 说明算法是局部优化，结果依赖起始模型；因此把参考来源视为解释流程的必要上下文，而不是新的实验观测。([relion2012] DOI [10.1016/j.jsb.2012.09.006](https://doi.org/10.1016/j.jsb.2012.09.006)，§2.1、§5 Conclusions)
- 对 AlphaFold 或其他预测模型，标明它是先验或建模起点；模型在同一 map 上拟合良好或几何合理，不构成独立实验验证。2024 社区报告指出，PDB 训练数据可能使预测模型带有已知结构 packing 信息，也认为相关验证方法仍需发展。**本审计建议：**若该预测模型支撑关键结论，寻找局部密度及独立数据等互补证据。([kleywegt2024] DOI [10.1107/S2052252524001246](https://doi.org/10.1107/S2052252524001246)，§5；[relion2012] DOI [10.1016/j.jsb.2012.09.006](https://doi.org/10.1016/j.jsb.2012.09.006)，§1、§2.1)
- 若模型对 map 进行了反复柔性拟合，可检查它是否仍与未参与拟合的数据一致。挑战规则 #4 **强烈鼓励**参赛者拟合未锐化、未加 mask 的 map 或其中一张 half-map；但该研究明确说并未评估 half-map 方法下的过拟合。因此它提供的是建模建议，不是已验证的交叉验证效果。**本审计推论：**若结论依赖该拟合结果，可查看另一张未参与拟合的 half-map 或其他独立证据；检查强度由主张和数据可得性决定。([em-challenge2021] DOI [10.1038/s41592-020-01051-w](https://doi.org/10.1038/s41592-020-01051-w)，Methods “Challenge process and organization” 中 challenge rules #4；Discussion；[kleywegt2024] DOI [10.1107/S2052252524001246](https://doi.org/10.1107/S2052252524001246)，§3.4 Recommendation 15)
- 核对重构所用点群、标准对称约定以及模型/map 的对称性。2024 社区报告建议验证 map 的点群信息及约定。**本审计判断：**若结论涉及非对称占据、非对称功能态或亚基缺失，再按该主张考察较低对称性重构或独立数据；对称性敏感性分析不是每项研究的固定门槛。([kleywegt2024] DOI [10.1107/S2052252524001246](https://doi.org/10.1107/S2052252524001246)，§3.3.5)

## cryo-EM 与 X-ray 的独立验证不能互换

- cryo-EM half-map FSC 比较独立半数据重构的一致性；map–model FSC 比较实验图与模型计算图，属于不同验证对象。全局 map–model FSC 是总体拟合信息。**本审计判断：**它不能替代具体残基或配体的局部检查；挑战研究发现，单残基与滑动窗口指标会有不同表现，近原子分辨率下局部拟合指标仍需按具体 map 解释。([kleywegt2024] DOI [10.1107/S2052252524001246](https://doi.org/10.1107/S2052252524001246)，§3.3.1、§3.4、Recommendation 15；[em-challenge2021] DOI [10.1038/s41592-020-01051-w](https://doi.org/10.1038/s41592-020-01051-w)，Figure 3d、Results “Evaluating metrics: local scoring”)
- X-ray 的 R-free 是模型精修时留出的 test reflections 上观测与计算结构因子振幅的一致性；它与半图 FSC 的对象、数据和数值尺度不同。不得用 R-free 替代 map–model 检验，也不能把 FSC=0.143、map–model FSC=0.5、R-free 或 CC1/2/CC* 的数值互相比较。([brunger1992] DOI [10.1038/355472a0](https://doi.org/10.1038/355472a0)，pp. 472–475；正文与交叉验证对比图；[karplus2012] DOI [10.1126/science.1218231](https://doi.org/10.1126/science.1218231)，正文 pp. 1030–1033、Figures 1–4；[kleywegt2024] DOI [10.1107/S2052252524001246](https://doi.org/10.1107/S2052252524001246)，§3.4)
- 两种实验都需交代 map/data 独立性和验证对象。X-ray R-free 的 withheld reflections 与 cryo-EM 的 half-maps 是各自的交叉验证设计，概念相通，但不构成同一种统计量；若原始验证数据不可得，将判断限定在已公开 map/model 与报告。([brunger1992] DOI [10.1038/355472a0](https://doi.org/10.1038/355472a0)，pp. 472–475；[scheres-chen2012] DOI [10.1038/nmeth.2115](https://doi.org/10.1038/nmeth.2115)，Figure 1；[kleywegt2024] DOI [10.1107/S2052252524001246](https://doi.org/10.1107/S2052252524001246)，§2.1 Recommendations 2–3、§3.3.1)
